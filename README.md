# 📒 Colección de Jupyter Notebooks

Este repositorio contiene una colección de notebooks de **análisis de datos, estadística y machine learning**.  
Cada notebook aborda un caso práctico, desde la exploración de datos (EDA) hasta la construcción de modelos predictivos.  

## 📌 Contenido
- Análisis exploratorio de datos (EDA)  
- Visualización de datos con Matplotlib y Seaborn  
- Modelos de Machine Learning con Scikit-learn  
- Ejercicios de estadística aplicada  
- Proyectos prácticos con datasets reales
